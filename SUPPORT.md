# Support

Read the deployment guide for your operating system and run `npm run doctor` before asking for help.

- Use GitHub Discussions for setup questions when it is enabled.
- Use the bug report template for reproducible project defects.
- Use PalDefender's own support channels for issues reproduced directly against its REST API.
- Report security problems privately as described in [SECURITY.md](SECURITY.md).

Never include `.env`, tokens, player IP addresses, or unredacted API results.

When asking for help, state that this is a self-hosted installation and provide the operating system, Node.js version, bot version or commit, and whether PalDefender is reached through loopback. Do not provide the actual guild ID or either token.
